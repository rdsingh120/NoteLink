# NoteLink

A simple note-taking web app with shareable links and authentication.

## Features

* Register & login
* Create notes
* View your notes
* Open a single note
* Share notes via public link

## Tech Stack

* MongoDB
* Express
* React
* Node.js

## How it works

1. Create an account
2. Create a note
3. Copy the share link
4. Open it anywhere (no login required)

## Run locally

### Server

```bash id="s1"
cd server
npm install
npm run dev
```

### Client

```bash id="s2"
cd client
npm install
npm run dev
```

## Goal

Built to practice shipping a complete full-stack app with minimal features.
